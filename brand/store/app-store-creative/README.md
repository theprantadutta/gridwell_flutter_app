# Gridwell · App Store creative assets

Two PNGs, RGB, with no alpha channel:

- `gridwell-product-page-header-3840x1646.png`: product page header (21:9). Art safe area 1646 × 661 at x 1097, y 493.
- `gridwell-universal-header-search-5244x2950.png`: Universal asset (16:9). It's used for both the product page header and search results. Art safe area 1402 × 962 at x 1921, y 660.

The wordmark, tagline and real game board sit inside each safe area. The pixel-art pictures behind them fill the rest of the canvas (the auxiliary art area), so it doesn't matter if devices crop them.

Upload: App Store Connect → your app → App Information → Creative assets. You can use the Universal asset alone for both placements, or the header file for the header plus the Universal file for search results.

There are no prices, URLs, awards or other-platform logos, in line with Apple's asset best practices. The tagline is English, so localise it if you add other languages.
