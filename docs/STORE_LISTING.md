# Store listing

Copy for Google Play and the App Store. Character counts are exact for the text inside each code
block (counted with Python `len()`, which matches how both consoles count plain ASCII text). Re-count
after any edit. Each store's limit is given in brackets.

Before you paste anything, read **Trademark note** at the end. It recommends a safer title and subtitle.

Facts every line below relies on (so an edit does not drift from the truth):

- 150 campaign puzzles in four collections, 5x5 up to 20x20, plus a 90-day daily pool. All of it is bundled.
- Every puzzle is verified at build time: solvable by pure line logic, exactly one solution, no guessing.
- Fully offline. Only leaderboards, backup and purchase verification use the network, and none of them block play.
- No sign-up needed. Players start as anonymous guests with a generated, editable pen name. Signing in with
  Google or email is optional and keeps progress across devices.
- Ads: rewarded video, plus an optional rewarded ad or an interstitial between puzzles. No banners.
- Remove Ads ($1.99, one-time) turns off the interstitials. Rewarded videos for extra hints stay optional.
- Premium ($2.99/month or $14.99/year, both with free trials): unlimited hints, no ads, free missed dailies,
  early access to new collections.

## Trademark note (read before publishing)

**"Picross" is a trademark of Nintendo.** Gridwell is not affiliated with, endorsed by, or connected to
Nintendo in any way. The word is used here only as a common genre search term.

The risk:
- **Title, name and subtitle are the highest-risk places.** A trademark in the app name can draw an
  IP complaint (Google Play's intellectual property policy, App Store Review Guideline 5.2) and get the
  listing rejected or removed, or force a rename after launch, which costs ranking and reviews.
- **App Store keywords:** Apple's guidelines forbid trademarked terms you have no rights to in the keyword
  field. That is why "picross" is **not** in the keyword list above, even though it is a target term.
- **Description prose** ("if you know these puzzles as picross, griddlers, hanjie...") is the lowest-risk
  use: descriptive, lowercase, alongside other genre names, never as the product's name. Even this is a
  judgment call; drop it if a complaint arrives.

Never write "Picross" capitalized as if it were Gridwell's name or a feature, never use Nintendo
characters, art or fonts, and never compare Gridwell to a named Nintendo game.

**Recommended safer wording (use this unless you accept the risk):**

| Field | Safer value | Count |
|---|---|---|
| Play title / App Store name | `Gridwell: Nonogram Puzzles` | 26 / 30 |
| App Store subtitle | `Logic Pixel Art, No Wifi` | 24 / 30 |
| App Store keywords | `griddler,japanese,crossword,hanjie,picture,cross,offline,daily,brain,calm,relax,mosaic,paint,number` | 99 / 100 |

With the safer name and subtitle, the words Gridwell, Nonogram, Puzzles, Logic, Pixel, Art, No and Wifi
are already indexed, so the keyword list drops "art" and "wifi" and adds "offline" and "daily".
"Picross" then appears only once, in lowercase description prose.

The project itself is named "Gridwell: Nonogram Picross" (in `CLAUDE.md` and elsewhere). That is
internal and does not need to change, but the store-facing name is the owner's call:
**Decided 2026-11-04: the store title is "Gridwell: Nonogram Puzzles".**
