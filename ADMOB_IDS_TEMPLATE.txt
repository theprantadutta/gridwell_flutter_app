GRIDWELL - ADMOB IDS
====================

Fill in the values after the "=" signs (no quotes, no spaces) and tell Claude
"admob ids are filled". They get copied into lib/services/ads/ad_config.dart
(release builds) and the Android manifest / iOS Info.plist. Debug builds
always use Google's test ids, so leaving a line empty is safe.

Where to find them: AdMob console → Apps → Gridwell → App settings (app id)
and → Ad units (unit ids). App ids contain "~", unit ids contain "/".

Publisher id (same account as your other apps): pub-9242904787767394

Gridwell uses three ad formats: rewarded, rewarded interstitial and
interstitial. No banners and no app-open ads (they would break the calm
puzzle-book feel).


# ---------- ANDROID ----------

# Where each format is used
# - REWARDED: the player taps "Hint" after the 3 free hints, or opens a
#   missed daily. They asked for it, so no intro screen is needed.
# - REWARDED_INTERSTITIAL: after a completed puzzle, when the player taps
#   "Next puzzle". A short intro offers a bonus hint for watching, with a
#   5-second countdown and a "No thanks" button (Google requires the intro
#   and the skip option). Skipping goes straight on with no ad.
# - INTERSTITIAL: the same slot, used only when no rewarded interstitial is
#   available.
#
# Notes
# - "Remove ads" turns off the between-puzzle ads (rewarded interstitial and
#   interstitial). Premium turns off all ads.
# - Between-puzzle ads: never before 6 solved puzzles, at most every 3rd
#   puzzle, at least 4 minutes apart, never on restart or resume.
# - If no rewarded ad can load (offline, no fill), the reward is granted
#   anyway, so the game never needs a connection.
# - Store product ids (Remove Ads, Premium monthly/yearly) are separate:
#   see docs/MONETIZATION_IDS.md. They are created after store approval.
