GRIDWELL - ADMOB IDS
====================

Fill in the values after the "=" signs (no quotes, no spaces) and tell Claude
"admob ids are filled". They get copied into lib/services/ads/ad_config.dart
(release builds) and the Android manifest / iOS Info.plist. Debug builds
always use Google's test ids, so leaving this empty is safe.

Where to find them: AdMob console → Apps → Gridwell → App settings (app id)
and → Ad units (unit ids). App ids contain "~", unit ids contain "/".

Publisher id (same account as your other apps): pub-9242904787767394

Gridwell uses only two ad formats: rewarded and interstitial.
No banners and no app-open ads (they would break the calm puzzle-book feel).


# ---------- ANDROID ----------
ANDROID_APP_ID=                 # ca-app-pub-9242904787767394~XXXXXXXXXX
ANDROID_REWARDED=               # ca-app-pub-9242904787767394/XXXXXXXXXX   extra hints, missed dailies (always optional)
ANDROID_INTERSTITIAL=           # ca-app-pub-9242904787767394/XXXXXXXXXX   only after "Next puzzle", frequency capped


# ---------- iOS ----------
IOS_APP_ID=                     # ca-app-pub-9242904787767394~XXXXXXXXXX
IOS_REWARDED=                   # ca-app-pub-9242904787767394/XXXXXXXXXX
IOS_INTERSTITIAL=               # ca-app-pub-9242904787767394/XXXXXXXXXX


# Notes
# - "Remove ads" turns off interstitials. Premium turns off all ads.
#   Rewarded videos stay as an optional choice for free players.
# - If no rewarded ad can load (offline, no fill), the reward is granted
#   anyway, so the game never needs a connection.
# - Interstitials: never before 6 solved puzzles, at most every 3rd puzzle,
#   at least 4 minutes apart, never on restart or resume.
# - Store product ids (Remove Ads, Premium monthly/yearly) are separate:
#   see docs/MONETIZATION_IDS.md. They are created after store approval.
